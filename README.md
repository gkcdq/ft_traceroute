# ft_traceroute

_This project has been created as part of the 42 curriculum by tmilin._

## 📝 Description

`ft_traceroute` is a simplified re-implementation of the standard system `traceroute` command (IPv4 version). It maps the path taken by packets to reach a target destination and measures the Round-Trip Time (RTT) for each hop. 

This project uses **RAW sockets** to craft custom `ICMP` (Echo Request) control packets and process intermediate network responses.

---

## ✨ Features

- **DNS Resolution**: Supports both IPv4 addresses and Fully Qualified Domain Names (FQDN).
- **Supported Options**:
  - `--help`: Displays the help list and usage instructions.
- **Statistics Engine**: Tracks transmitted/received packets, calculates packet loss percentage, and computes RTT metrics (min/avg/max).
- **Signal Handling**: Ensures a clean exit and triggers a final statistics display upon receiving `SIGINT` (Ctrl+C).

## 🛠️ System Functions Used & Explanations

This project relies exclusively on the allowed system functions to handle sockets, memory management, and network resolution.

### 1. Name Resolution and DNS
* **`getaddrinfo`**: This is the entry point for network resolution. It takes the user-supplied parameter (either a raw IP address or a domain name like `google.com`) and queries the DNS to populate a `struct addrinfo` containing a usable network IP address. It supersedes the obsolete `gethostbyname` function.
* **`freeaddrinfo`**: Essential for preventing memory leaks. It properly frees the dynamically allocated memory generated by `getaddrinfo`.
* **`getnameinfo`**: Used for *Reverse DNS* lookups. At each hop, it takes the IP address of the responding router and attempts to resolve its Fully Qualified Domain Name (FQDN). If the lookup fails, the program falls back to displaying the raw IP.
* **`inet_ntop`** (or `inet_ntoa`): Converts a binary IP address (stored within the network structure) into a human-readable string (e.g., `172.217.22.142`) so it can be formatted and printed to the terminal.

### 2. Socket Management (Networking)
* **`socket`**: Creates the communication endpoint (the network file descriptor). In this project, a raw socket (`SOCK_RAW`) is opened using the `IPPROTO_ICMP` protocol, allowing us to craft and read our own ICMP packets.
* **`setsockopt`**: Used to configure options on the socket. In this implementation, it serves two purposes:
    1. Setting `SO_RCVTIMEO` (a one-second receive timeout) to prevent `recvfrom` from blocking the program indefinitely if a router drops a packet or refuses to respond.
    2. Modifying the TTL at the IP layer for each hop.
* **`sendto`**: Transmits the custom-crafted ICMP packet (Echo Request) through the socket to the destination address.
* **`recvfrom`**: Listens for and captures incoming packets on the socket. It retrieves both the data payload (the buffer) and the network address (`struct sockaddr_in`) of the intermediate router that sent the ICMP error reply.
* **`close`**: Properly closes the socket's file descriptor upon program termination or fatal error to release system resources.

### 3. Time Management & Precision
* **`gettimeofday`**: Retrieves the current system time with microsecond precision. It is called twice per probe: once immediately before `sendto`, and once right after a successful `recvfrom`. The delta between these two timestamps provides the **RTT** (Round-Trip Time) in milliseconds.

### 4. System Identifiers
* **`getpid`**: Fetches the unique Process ID (PID) of the running program. This ID is copied into the `ID` field of the ICMP header before transmission. Upon reception, it allows `parse_reply` to verify that the incoming ICMP packet belongs to our process and is not a response meant for another network tool running on the machine.

## 📈 Global Data Flow Logic

```bash
[getuid / Check Root] ──> [getaddrinfo / Resolve Target] ──> [socket / Create Channel]
│
┌─────────────────────────────────────────────────────────────────────┘
│
▼
[Loop Hop: TTL 1 to 30]
├──> For each probe (1 to 3):
│       ├──> Record timestamp (gettimeofday)
│       ├──> Send packet (sendto)
│       ├──> Receive reply / Timeout (recvfrom)
│       └──> Record timestamp (gettimeofday) -> Compute RTT
├──> Extract Router Hostname (getnameinfo) & IP (inet_ntop)
└──> Print results in real-time
│
▼
[Teardown] ──> [freeaddrinfo] ──> [close socket] ──> [Clean Exit]
```

## 🚀 Usage

- ⚠️ Note: Because this program uses Raw Sockets (SOCK_RAW), it must be executed with root privileges (sudo).

```Bash

# Compile the project
make

# Simple trace to an IP address
sudo ./ft_traceroute 8.8.8.8

# Trace a domain name
sudo ./ft_traceroute google.com

# Show help
./ft_traceroute --help
```
